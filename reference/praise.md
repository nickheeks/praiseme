# Deliver praise

This function is super useful when you're feeling sad and is useful for
everyone.

## Usage

``` r
praise(name, punctuation = "!")
```

## Arguments

- name:

  A character string; the name of the person to praise

- punctuation:

  A character string; emphasis for the praise

## Value

A character string with praise

## Examples

``` r
praise("Thomas")
#> You're the best, Thomas!
praise("Alice", "!!!")
#> You're the best, Alice!!!
```
